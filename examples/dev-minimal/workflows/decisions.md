# decisions — 決策記錄（定了什麼、前提是什麼）

[WORKFLOWS](../WORKFLOWS.md)｜[INDEX](../INDEX.md)

留下「定了什麼」：git log 找得回改了什麼，找不回**當時定下的規則與它成立的前提**。活狀態記「未完的」，這裡記「已定的」：只記結論、前提與使用者原文；比較過的方案與 AI 寫的理由不記（[tidy 內容精簡](tidy/content-trim.md)），要查靠 git 歷史。

**何時用**：在兩個以上可行方案裡選了一個，且日後可能被問「當初定的是什麼、還成立嗎」。
**何時不用**：只有一條路，或改了隨時可回頭的小事。決策過程本身要結構化評估 → knowledge 包的 decide 工作流，結論再落到這裡。

# user — 使用者偏好與確認邊界

[common/README](README.md)

agent 每次不用重猜的事。always-on 鐵律在 AGENTS.md；這裡是**這位使用者**的偏好——改了就改這裡，不改鐵律。

| 項目 | 設定 |
|------|------|
| 語言 | 繁中；日文原文（例句、單字、假名、漢字）保留日文寫法，不轉成中文用字 |
| 分支慣例 | 直接 commit main，一個人的庫不開 PR；commit 訊息一行講清楚動了哪條線 |
| 直接做、不用問 | 新增 / 修改筆記檔、補單字與例句、調整目錄分類、跑唯讀指令 |
| 一定先問 | 刪筆記檔、大批改檔名或搬目錄、動 `plans/` 裡已定的計畫（push 與對外動作依鐵律 2）|
| 回覆風格 | 短、先結論；日文詞第一次出現附假名讀音；不要每段都 bullet |
| 時區 | Asia/Taipei（日期一律 `YYYY-MM-DD`）|

## 領域詞彙（長出來才建）

術語多到 agent 常猜錯時，開 `glossary.md`（`詞 | 意思 | 別名`）並在 [common/README](README.md) 加一列。
